# [Modulation Identification] A Lightweight Distributed Learning-Based Autonomous Modulation Classification Method for Edge Devices [with MATLAB Code]

Introduction: The Internet of Things (IoT) is a paradigm for information services that defines an interconnected dynamic environment for the integration of end devices, achieving seamless connectivity between devices and data transmission. With the increase in the number of terminal devices, a large amount of data is generated within IoT devices, often stored in untrusted storage[1]-[3]. Additionally, IoT devices are vulnerable to external malicious attacks[5]-[7]. Therefore, when devices fail to recognize external malicious attacks, they face the risk of data leakage. Autonomous Modulation Classification (AMC) is a promising technology that can be applied to receivers to distinguish different types of modulation signals[8], which is an important method for identifying malicious attacks from the physical layer, such as Spectrum Sensing Data Falsification (SSDF) attacks and jamming attacks[9]. Recently, AMC has played a significant role in military and civilian communication, such as cognitive radio and link adaptive.
Over the past few decades, typical AMC methods have included likelihood-based AMC (LBAMC) [10]-[15] and feature-based AMC (FBAMC) [16]-[22]. The LBAMC method models classification problems as composite hypotheses and uses a likelihood function to determine the correct modulation type. Typically, based on different likelihood functions, the LBAMC method mainly includes average likelihood ratio test (ALRT) [10], [11], generalized likelihood ratio test (GLRT) [12], [13], and hybrid likelihood ratio test (HLRT) [14], [15]. Although LBAMC can achieve Bayesian-optimal performance, it requires high computational complexity, making it difficult to apply to real systems without channel state information.
Unlike the LBAMC method, the FBAMC method employs methods that extract specific features from received signals and complete classification tasks. It can handle signals with unknown statistical channel characteristics, offering lower computational complexity compared to the LBAMC method [16]. Existing FBAMC methods typically extract statistical features such as cyclic statistics, wavelet transforms, cumulants, etc., for final decision-making. Traditional machine learning (ML) methods, such as decision trees and k-nearest neighbors (KNN), are also widely used in FBAMC methods as classifiers. However, these traditional methods require manual feature extraction, which results in poor classification performance when dealing with multi-signal classification tasks.
In recent years, deep learning (DL) has achieved great success in many fields, including wireless communication [23]-[26], device attack detection in the Internet of Things (IoT) [27]-[28], and IoT malware classification [29]. The advantages of DL methods compared to traditional ML methods can be summarized as follows: Firstly, DL methods can internally implement feature learning without the need for specialized feature extraction, avoiding complex feature engineering based on expert knowledge. Secondly, higher-level features can be extracted through the combination of different DL layers to achieve better performance. Therefore, an increasing number of scholars are attempting to apply DL methods to FBAMC methods to improve classification accuracy [30]-[47].
1) Neural Network Design for AMC Method: Currently, most deep learning-based methods are directly borrowed from the fields of image processing or natural language processing [30] to [40], [44]. However, networks specifically designed for signal modulation are rare. Therefore, to further improve the classification accuracy of AMC, it is necessary to design networks based on the characteristics of modulation signals, allowing for learning of signal features from multiple perspectives. For example, Lin et al. [31] used Short Time Fourier Transform (STFT) to transform the modulated signal into its spectrum, extracting more rich features from the time-frequency analysis perspective. Chang et al. [32] adopted I/Q format and A/P format under different Signal-to-Noise Ratios (SNR), integrating the features of both types of signals to achieve better classification performance.
2) Lightweight Neural Networks for DecentAMC: Existing deep learning-based AMC methods typically use localized learning (LocalAMC) or centralized learning (CentAMC) algorithms based on convolutional neural networks (CNN) or deep residual networks (ResNet). LocalAMC means that each edge device (ED) relies on a limited local dataset for training, without using datasets from other EDs, which leads to limited performance. CentAMC refers to multiple EDs uploading their local datasets to a central device (CD) for training, as the model is trained using multiple datasets, thus offering better performance, as shown in Figure 1. However, during the data sharing process, CentAMC poses challenges to the computational and storage capabilities of the CD, and threatens data privacy and security. To address the issues with LocalAMC and CentAMC, [33] proposed a Distributed Learning AMC (DistAMC) method based on CNN, which enables data decentralization by allowing multiple devices to upload model weights rather than datasets to the CD. However, the CNN model used in DistAMC has a large scale, and requires frequent updates of model weights, which can lead to significant communication costs. Moreover, CNNs are highly complex, making it difficult to deploy them on EDs. Therefore, we attempted to deploy a lightweight network specifically designed for modulation signals within the distributed learning (DecentAMC) approach.
We have proposed related deep learning-based AMC work into two groups. Firstly, high-performance networks, whose contributions mainly come from combining different network layers or deepening the network depth to achieve high classification performance. Secondly, lightweight networks, aimed at reducing the complexity of the network and making it easier to deploy on EDs.
1) High-Performance Networks: Initial DL-based AMC methods, such as CNN-AMC (CNN-AMC), were based on CNNs [30]. These methods outperformed FBAMC and had faster parallel computing speeds. Zhang et al. [34] proposed an improved CNN-AMC network that fused handcrafted features from images and signals to extract more advanced features, which can improve classification accuracy compared to previous work. Another optimized CNN-AMC network, named SBCNN, enhanced prediction accuracy by designing optimal filter sizes, demonstrating high robustness on complex datasets [36]. Lin et al. [31] designed a time-frequency attention mechanism for CNN-AMC to understand which frequency, channel, and temporal features are more meaningful in modulation classification networks, outperforming other attention mechanisms. In [37], multiple CNN models were trained for multitask learning under different SNR levels, with each CNN model sharing model weights with others, which could be applied to real-world noisy scenarios and achieve better generalization and robustness. In the field of image processing, besides CNNs, numerous excellent networks have been applied to AMC. Qi et al. [40] proposed a method for implementing AMC based on deep ResNets, which effectively distinguishes 16 modulation signals. The DPN proposed in [35] consists of multiple residual blocks, which deepens the network while avoiding gradient vanishing, and is superior to other signal processing algorithms when SNR is above 14 dB.
Additionally, modulation signals not only possess spatial characteristics but also temporal ones. Therefore, in [44], a CNN-LSTM network was proposed that utilizes CNN for extracting spatial features and LSTM for extracting temporal ones to achieve the integration of both time and space features. In [45], another multi-channel learning framework based on the CNN-LSTM network was introduced, which achieved better recognition accuracy, especially for higher-dimensional schemes (16-QAM and 64-QAM), and had a faster convergence speed compared to other existing DL networks.
2) Lightweight Networks: Many scholars have adopted different methods to realize lightweight networks. [38] proposed an AMC lightweight network based on group-level sparsity, which enables the model to prune itself to achieve a compact network and addresses recognition confusion types through an improved two-step training method. Teng et al. [49] introduced a channel compensation mechanism and a DL approach based on cumulative activation features, reducing training overhead under time-varying fading channels. [39] proposed an AMC method based on neural network structure search (NAS), which can automatically design high-performance network structures with lower model complexity. Luan et al. [50] applied shuffling units and GRU gates to make the network lighter, addressing the issue of time-consuming problems under impulse noise. Wang et al. [41] proposed an AMC lightweight network using DL and compression-sensing combined, making CNNs lightweight while slightly losing performance. Lin et al. [42] introduced an improved lightweight AMC method that reduces the size of neural networks by considering pruning techniques to achieve promising edge applications. [47] proposed a lightweight neural network based on SCNN for AMC, mainly using SCNN to replace part of the standard convolution in CNNs and removing some FC layers from CNNs. Compared to CNNs, the model complexity of SCNN is reduced by about 94%. In [43], an optimized CNN network MCNet was proposed, consisting of multiple convolutional blocks with asymmetric convolution kernels or added. MCNet can effectively capture the spatial correlation of modulation signals as the number of convolutional blocks increases. Another lightweight network based on phase estimators and Transformer (PET), using CNN layers and GRU layers as spatial and temporal feature extraction layers, can reduce by one-third the parameter count compared to existing state-of-the-art networks, with slight performance loss.
This paper proposes an efficient and lightweight neural network for the DecentAMC method, namely the Multi-Channel and Multi-Functional Block Spatio-Temporal Mixture Deep Neural Network (MCMBNN), to address the issue of insufficient computational power and storage limitations when applying traditional deep learning models to ED implementations of AMC.
1) For the problem of modulation signal classification, a new MCMBNN is proposed that uses three channels to extract features from the modulation signals, ultimately achieving feature fusion across different signal channels. Additionally, the MCMBNN can extract phase, spatial, and temporal features of the modulation signals with lower model complexity through specially designed functional modules. Experimental results show that the MCMBNN has good robustness against different datasets.
2) A novel training method, DecentAMC, is introduced, which collaboratively updates model weights in multiple EDs and uploads them to CD for model aggregation, avoiding data privacy leakage and reducing the computational pressure on the CD.
3) Experimental results indicate that the DecentAMC method based on the MCMBNN can be effectively deployed on electronic devices, benefiting from low communication costs.
The algorithm flowchart in this section details a new lightweight neural network, MCMBNN. As shown in Figure 3, the lightweight network MCMBNN consists of multiple functional blocks, including GRU layers and dense layers with Softmax. Based on the specific functions of different network layers, MCMBNN can be divided into three parts: 1) Multi-Channel Pet Module (A part); 2) Multi-Channel Spatial Feature Extraction Module (B part); 3) Time Feature Extraction and Softmax Module (C part).
A. Multi-Channel Learning
The original IQ channel signals are fed into both A and B parts simultaneously. Then, the input signals are divided into three streams: raw IQ signals, I channel signals, and Q channel signals, inspired by the multi-channel learning framework [45]. The reason for splitting the signals is that there is significant difference between the I channel and Q channel signals, and the extracted features from the multi-channel can form complementary relationships.
B. Phase Estimator and Transformer Module
Due to the effects of channel noise and attenuation, the original IQ channel signals typically exhibit phase offset characteristics. Therefore, the PET module can be applied to process the raw AMC signals to extract phase offset features, thereby improving overall classification accuracy [46]. As shown in Figure 4, the phase estimator block consists of a flat layer, a dense layer with only one unit, and a linear activation function layer. The raw IQ channel signals undergo a vector dimension transformation from (2,128) to (1,256) through the flat layer to meet the input dimension of the dense layer. Subsequently, this vector can acquire rich phase features through the dense layer. Finally, we use a linear activation function to estimate the phase parameters.
C. Spatial Feature Extraction Block
As shown in Figure 5, three IQ channel signals are parallel input into two different convolutional blocks for extracting higher-level spatial features from the three signal channels. The first IQ mixed channel signal is input into the MC 2D block 1, which is depicted in Figure 6(a). The MC 2D-Block is designed with three parallel 2-D standard convolution layers, each with two asymmetric convolution kernels ((2,8), (8,2)) and an (1,1) convolution kernel. Similar to [43], deploying asymmetric convolution kernels allows for extracting signal space features along both horizontal and vertical dimensions without compromising the quality of spatial feature extraction, compared to traditional symmetric convolution kernels [(8,8) convolution kernel] reducing training parameters. Then, ReLU layers follow each convolution layer to enhance the network's non-linearity and prevent gradient vanishing.
D. Time-Domain Feature Extraction and Softmax Block
We utilize an Add layer to integrate phase offset features and signal space features. Subsequently, a GRU layer with 128 units is employed to extract temporal features. Compared to the LSTM layer, the GRU layer has a simpler network structure and can also effectively extract temporal features. Finally, a Dense layer with C units (C being the number of modulation signals) realizes the final classification of the modulated signals, using a softmax activation function. As mentioned above, the final MCMBNN consists of three parts, employing three different strategies to design lightweight neural networks. First, the PET block is applied to process the raw signals to extract phase offset features. Second, multi-group asymmetric convolution blocks and group convolution are used to extract spatial features. Third, a GRU layer is utilized to extract temporal features. At the same time, to ensure the network's classification performance, we employ multi-channel input to extract complementary features between different channels.
In this section, we conducted two experiments to evaluate the proposed lightweight neural network (MCMBNN) and the proposed training method (DecentAMC method) based on three datasets. Firstly, we compared MCMBNN with six CentAMC-based SoA networks, which include three high-performance networks CNN [30], [33], MCLDNN [45], CNN-LSTM [44], and three lightweight networks SCNN [47], MCNet [43], and PET-CGDNN [46]. MCLDNN and PET-CGDNN use multi-channel learning frameworks, while other networks choose direct input of IQ signals. MCLDNN, CNN-LSTM, and PET-CGDNN contain time feature extraction units similar to LSTM or GRU, while CNN, MCNet, and SCNN are composed only of spatial feature extraction units. On this basis, aerobic learning experiments were conducted to examine the impact of each module on the model complexity and classification performance of MCMBNN. In the second experiment, different networks were combined with DecentAMC method to achieve decentralized learning based on three datasets.
1) Datasets: Three datasets are used to test the generalization performance of the model: 1) RadioML.2016.10A; 2) RadioML.2016.10B [48]; 3) MATLAB [47]. The RadioML.2016.10A and RadioML.2016.10B datasets are based on the standard open dataset for GNURAdio. The difference between the data generated by GNURAdio and MATLAB is that the IQ signal generated by GNURAdio is limited to follow the analog baseband, while the IQ points in MATLAB are discrete jumps [56]. Therefore, the simulation based on these two types of datasets can fully demonstrate the performance. Each sample has a signal length of 128, and the input signal samples are (2, 128), because the signal is input into the neural network as IQ samples. The modulation signal types for the above three datasets are as follows.
1)RadioML.2016.10A: {BPSK, 8 PSK, CPFSK, GFSK, PAM 4, 16 QAM, 64 QAM, QPSK, AM-DSB, AM-SSB, WBFM}, SNR range from -20 to 18 dB, with an interval of 2 dB. The number of samples is 220,000.
2)RadioML.2016.10B: {BPSK, 8 PSK, CPFSK, GFSK, PAM 4, 16 QAM, 64 QAM, QPSK, AM-DSB, WBFM}, The RadioML.2016.10B dataset is a larger version of RadioML.2016.10A, containing 1,200,000 samples.
3) MATLAB generated dataset: {BPSK, QPSK, 8 PSK, 2FSK, 4FSK, 8 FSK, 16 QAM, 128 QAM, 256 QAM}, with a usage range of -10 to 20 dB SNR and an interval of 2 dB. The number of samples is 720,000. Additionally, frequency, phase, and time offsets are introduced as f0 = 0.1, θ = π/16, and τ = 7.
2) Simulation settings: We assume there are ten EDs and one CD. Therefore, each dataset is divided into ten equal parts to simulate ten different EDs. The number of training periods is set to 500. The parameters α, β1, and β2 for Adam are the preset values in Keras, namely, {0.001, 0.9, 0.999}. We use learning rate decay to train the model, where the learning rate will decrease by 80% after ten training periods without improvement in the model. The experimental platform is a GTX 2080 Ti, DL framework is Tensorflow 1.10.0 and Keras 2.2.4.

Conclusion In this article, we propose a lightweight neural network MCMBNN and a distributed training method DcentAMC method. The design of MCMBNN is achieved through the combination of three lightweight modules (PET module, spatial feature extraction module, and temporal feature extraction & Softmax module), respectively adopting different lightweight ideas to further realize the overall lightweight network. The DecentAMC method uses FL to train the AMC model to achieve distributed learning.
Experimental results show that MCMBNN achieves superior classification performance with lower model complexity on the basis of multiple block classification. Moreover, the DcentAMC method based on MCMBNN can be deployed on ED, achieving relatively better classification performance and lower communication overhead. This will address the issues related to insufficient ED computing power and data leakage associated with traditional DL models and CentAMC methods. Future work will attempt to quantify model weights to further reduce communication overhead. We have also conducted several experiments based on datasets that more accurately represent real-world scenarios.
